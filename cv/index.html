EdgeBlackBox · 边缘黑匣子 进行中

基于 RK3568 的隐私保护型多模态边缘事件记录黑匣子（旗舰项目）· 统一事件抽象 · 双脑判定 · 密封证据链

  • 提出统一事件抽象，将 IMU / 环境 / 音频 / CAN FD / 视频五模态归一为 24 维特征与 5 类事件本体，以结构性约束杜绝"传感器堆叠"式架构；C 与 Python 特征提取逐位一致（-ffp-contract=off 定点契约）。
